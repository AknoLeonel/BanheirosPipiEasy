# PipiEasy

Site de locação de banheiros químicos para obras e eventos no DF e entorno.

[![Ver site no ar](https://img.shields.io/badge/Ver%20site%20no%20ar-00F5FF?style=for-the-badge&labelColor=0D1117)](https://banheiros-pipi-easy.vercel.app) [![Portfólio](https://img.shields.io/badge/Portfólio-FF00E4?style=for-the-badge&labelColor=0D1117)](https://aknoleonel.github.io)

## Sobre o projeto

Landing page da PipiEasy, que aluga banheiros químicos para obras, eventos e agronegócio. O site apresenta o catálogo de modelos, os números da empresa e leva o visitante a pedir orçamento.

## Destaques

- Pedido de orçamento rápido logo na primeira tela
- Catálogo de modelos de cabine com características de cada um
- Indicadores: entrega em até 24h, locações realizadas e licenças em dia
- HTML, CSS e JavaScript puros, com sitemap.xml e robots.txt para SEO

## Tecnologias

HTML · CSS · JavaScript

## Rodando localmente

Este é um site estático. Basta abrir o `index.html` no navegador ou usar uma extensão como o Live Server.
